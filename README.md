# Оценка компромисса между алгоритмическим ускорением и накладными расходами инференса нейросетевой эвристики в графовых планировщиках

## Описание проекта

Исследовательский проект в рамках курса «Машинное зрение» (МТУСИ, группа БВТ2304), посвященный количественной оценке применения обучаемых нейросетевых эвристик в алгоритме A* для планирования движения автономных транспортных средств.

**Автор:** Тюрина Александра Алексеевна  
**Группа:** БВТ2304  
**Файл для просмотра** experiment2.ipynb

## Цель исследования

Количественно оценить компромисс между временем планирования и степенью субоптимальности пути при использовании нейросетевой эвристики (A*-LH) по сравнению с классическим Weighted A* (ε=1.05) на картах с плотностью препятствий от 10% до 50%.

## 🔬 Методология

### Архитектура CNN
- Легкая сверточная сеть (~9.5 тыс. параметров)
- 3 сверточных слоя (Conv2D): 2→16→32→16
- Ядра 3×3, активация ReLU
- Global Average Pooling + Linear слой

### Алгоритмы сравнения
1. **Optimal A*** — с эвристикой Octile (гарантирует оптимальность)
2. **Weighted A*** (ε=1.05) — основной baseline
3. **A*-LH** (Proposed) — с обучаемой нейросетевой эвристикой

### Среда эксперимента
- 2D grid-мир 30×30
- 8-связная сетка с запретом corner-cutting
- Плотности: 10%, 20%, 30%, 40%, 50%
- Hardware: Apple M4 (CPU, однопоточный режим)

## Основные результаты

- **Гипотеза об ускорении не подтвердилась**: A*-LH оказался статистически значимо медленнее Weighted A* на всех протестированных плотностях (медианное отношение времени ~35–48×)
- **Качество пути сохранено**: медианное отклонение от оптимума 0.0%, максимум 3.9%
- **Механизм замедления**: накладные расходы фреймворка PyTorch на поузловой инференс (~128 мкс на вызов) доминируют над алгоритмическим выигрышем
